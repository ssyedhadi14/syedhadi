01

Install the prerequisites

Claude CodeSigned in with a Claude Pro, Max or Team plan, or API credits
Python 3.10+Runs the helper tools in the repo
BunRuns any job board CLIs you add
LaTeXTeX Live, MacTeX or MiKTeX with lualatex and xelatex
ghGitHub CLI, signed in
02

Make a private copy

gh repo clone ai-job-search-dev/ai-job-search
cd ai-job-search
git remote rename origin upstream
gh repo create ai-job-search --private \
  --source=. --remote=origin --push

Never fork for your own search. A fork of a public repo is always public, and setup writes your details into tracked files.

03

Build your profile

claude     # opens Claude Code in the repo
/setup     # run inside Claude Code

Drop your CV PDF, LinkedIn export and past applications into documents/, paste one CV in chat, or let it interview you. Rerun any time you add material.

Check LaTeX is ready, a PDF means yes:

cd cv && lualatex main_example.tex
04

Add job boards (optional)

Without a board, /scrape uses web search. To add one, copy its folder from community-portals into .agents/skills/, review the code, then run:

python3 tools/install_portal_clis.py

No board for your market? /add-portal builds one from its URL.

05

Run the workflow

/scrapeSearches your boards for roles that match your profile and removes duplicates
/rankScores every new posting against your profile and returns a shortlist with honest gaps
/apply <url>Checks fit, drafts the CV and cover letter, gets a second agent's review, then compiles and checks the PDFs. Paste the job text if the page sits behind a login
/interviewBuilds a prep pack for the next round, maps likely questions to your STAR stories and runs a mock
/outcomeLogs the result, archives what you sent and drafts follow ups for applications that went quiet
!

Use it well

  • Feed it detail. Projects, tools and measurable results per role make every application specific.
  • Read each CV and letter before you send it. You stay the one who applies.
  • It never invents experience. Gaps stay visible, so prepare for them.
  • Postings are untrusted input. The integrity gate flags hidden instructions.
