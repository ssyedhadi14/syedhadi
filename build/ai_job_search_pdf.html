Set up AI Job Search on Claude Code

The open source framework that finds roles, scores fit, tailors your CV and cover letter, and preps every interview round. From zero to your first tailored application in about 30 minutes.

Free, MIT licenseRuns on your machineNeeds a Claude plan or API credits

1Install the prerequisites

Claude CodeThe CLI, signed in with a Claude Pro, Max or Team plan, or API credits
Python 3.10+Runs the helper tools in the repo
BunRuns any job board CLIs you add
LaTeXTeX Live, MacTeX or MiKTeX. Needs lualatex (CV) and xelatex (cover letter)
ghGitHub CLI, signed in, to make your private copy

2Make a private copy

gh repo clone ai-job-search-dev/ai-job-search
cd ai-job-search
git remote rename origin upstream
gh repo create ai-job-search --private \
  --source=. --remote=origin --push

Do not fork for your own search. A fork of a public repo is always public, and setup writes your details into tracked files.

3Build your profile

claude          # opens Claude Code in the repo
/setup          # inside Claude Code

Put your CV PDF, LinkedIn export and past applications in documents/ first, paste a single CV in chat, or let it interview you. Re-run any time you add material.

4Add job boards (optional)

With no board installed, /scrape uses web search. To add one, copy its folder from community-portals into .agents/skills/, review the code, then run:

python3 tools/install_portal_clis.py

No board for your market? /add-portal builds one from its URL.

5Run the workflow

/scrapeSearches your boards for roles that match your profile and removes duplicates
/rankScores every new posting against your profile and returns a shortlist with honest gaps
/apply <url>Checks fit, drafts the CV and cover letter, gets a second agent's review, then compiles and checks the PDFs. Paste the job text instead of a URL if the page is behind a login
/interviewBuilds a prep pack for the next round, maps likely questions to your STAR stories, runs a mock
/outcomeLogs the result, archives what you sent, drafts follow ups for applications that went quiet

6Check it works

cd cv && lualatex -interaction=nonstopmode \
  main_example.tex && cd ..

A PDF means LaTeX is ready. On TinyTeX or BasicTeX, first install: moderncv fontawesome5 fontawesome6 academicons needspace titlesec textpos xltxtra xunicode realscripts with tlmgr install.

!Use it well

  • Feed it detail. Projects, tools and measurable results per role make the applications specific.
  • Read every CV and letter before you send it. You stay the one who applies.
  • It never invents experience. Gaps stay visible, so prep for them in interviews.
  • Treat postings from unfamiliar boards with care. The integrity gate flags hidden instructions.
