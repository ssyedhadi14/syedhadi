Every software company needs three kinds of people

The role directory

All 28 software roles, in plain words

What each role does, who enjoys it, the three skills to learn first, the job titles to search for and one project you can finish in 30 days.

Build the product

Backend Engineer

Builds the servers, APIs and databases that every app runs on.

You will enjoy it if you like logic puzzles and making things work behind the scenes.

Skills, first job titles and a starter project
  • One language well (Java, Python, Go or Node.js)
  • SQL and one database
  • REST APIs and Git

First job titles: Software Engineer, Backend Developer, SDE 1

30 day starter project: Build a URL shortener API with sign in, rate limits and a database, then deploy it.

Build the product

Frontend Engineer

Builds the screens people click, tap and scroll in the browser.

You will enjoy it if you care how things look and feel, and you like seeing your work instantly.

Skills, first job titles and a starter project
  • HTML, CSS and JavaScript
  • React or Vue
  • Accessibility and responsive layouts

First job titles: Frontend Developer, UI Engineer, SDE 1

30 day starter project: Rebuild your college website as a fast, mobile friendly React app.

Build the product

Full Stack Developer

Builds both the screens and the server, end to end.

You will enjoy it if you want to ship a whole product on your own.

Skills, first job titles and a starter project
  • JavaScript or TypeScript
  • React plus Node.js or Django
  • A database and basic cloud hosting

First job titles: Full Stack Developer, Software Engineer, SDE 1

30 day starter project: Ship a small SaaS: a class notes sharing app with login, uploads and search.

Build the product

Mobile App Developer

Builds the Android and iOS apps on people's phones.

You will enjoy it if you love apps and want your work in a million pockets.

Skills, first job titles and a starter project
  • Kotlin or Swift, or Flutter for both
  • Mobile UI patterns
  • Publishing to the Play Store

First job titles: Android Developer, iOS Developer, Flutter Developer

30 day starter project: Publish an expense splitter app for your hostel or friends on the Play Store.

Build the product

DevOps and Cloud Engineer

Automates how code gets built, tested and shipped to the cloud.

You will enjoy it if you like systems, automation and making things run without manual work.

Skills, first job titles and a starter project
  • Linux and shell scripting
  • Docker and Kubernetes basics
  • One cloud (AWS, Azure or GCP)

First job titles: DevOps Engineer, Cloud Engineer, Platform Engineer

30 day starter project: Containerise a sample app and deploy it with a CI pipeline that runs tests on every push.

Build the product

Site Reliability Engineer

Keeps big systems fast and online, and fixes them when they break.

You will enjoy it if you stay calm under pressure and enjoy chasing down why something failed.

Skills, first job titles and a starter project
  • Linux and networking
  • Monitoring with Prometheus and Grafana
  • Scripting in Python or Go

First job titles: SRE, Production Engineer, Infrastructure Engineer

30 day starter project: Set up monitoring and alerts for a self hosted app, then break it on purpose and write the incident report.

Build the product

QA and Test Automation Engineer

Finds bugs before customers do, and automates the tests.

You will enjoy it if you notice every small mistake and enjoy breaking things.

Skills, first job titles and a starter project
  • Testing basics and writing test cases
  • Selenium or Playwright
  • One scripting language

First job titles: QA Engineer, SDET, Automation Tester

30 day starter project: Write an automated test suite for a public demo shop site and publish the report on GitHub.

Build the product

Embedded and IoT Engineer

Writes the software inside devices, from smart watches to cars.

You will enjoy it if you like electronics and seeing code move real hardware.

Skills, first job titles and a starter project
  • C and C++
  • Microcontrollers like Arduino or ESP32
  • Basic circuits and sensors

First job titles: Embedded Software Engineer, Firmware Engineer, IoT Developer

30 day starter project: Build a room temperature monitor with an ESP32 that sends readings to a phone dashboard.

Turns company data into dashboards and answers that guide decisions.

You will enjoy it if you like finding the story inside numbers and explaining it to others.

Skills, first job titles and a starter project
  • Excel and SQL
  • Power BI or Tableau
  • Basic statistics

First job titles: Data Analyst, Business Intelligence Analyst, MIS Analyst

30 day starter project: Analyse a public dataset (cricket, movies or city transport) and publish a dashboard with five insights.

Data and AI

Uses statistics and models to predict what happens next.

You will enjoy it if you enjoy maths and want to answer hard questions with data.

Skills, first job titles and a starter project
  • Python with pandas
  • Statistics and probability
  • Scikit learn basics

First job titles: Data Scientist, Junior Data Scientist, Analytics Associate

30 day starter project: Predict house prices or exam results from a public dataset and explain which factors matter most.

Data and AI

You will enjoy it if you like plumbing work that makes everyone else faster.

Skills, first job titles and a starter project
  • SQL and Python
  • ETL tools like Airflow
  • Cloud warehouses like BigQuery or Snowflake

First job titles: Data Engineer, ETL Developer, Analytics Engineer

30 day starter project: Build a daily pipeline that pulls weather data from an API, cleans it and loads it into a database.

Data and AI

Machine Learning Engineer

Trains models and puts them into real products at scale.

You will enjoy it if you like both coding and maths, and want to ship AI that real users touch.

Skills, first job titles and a starter project
  • Python and PyTorch
  • Linear algebra and statistics

First job titles: ML Engineer, AI Engineer, Applied Scientist

Data and AI

Skills, first job titles and a starter project

Skills, first job titles and a starter project
  • Networking, Linux and web basics

Questions students ask

Before you pick

Which software job is best for freshers in India?

There is no single best job. Backend, full stack and data analyst roles have the most fresher openings. Security, cloud and AI roles are growing fastest. Sales development and customer success roles hire graduates from any stream. Pick the role whose daily work you would enjoy, then build one portfolio project for it.

Can I get a software job without a computer science degree?

Yes. Product, design, data analyst, sales, marketing, customer success, technical writing and IT support roles all hire graduates from commerce, arts and other engineering branches. Even engineering roles care more about a public portfolio and a coding test than about the degree name.

Do I need to know coding for every software job?

No. About half the roles in a software company, like product marketing, sales, customer success, design and project management, need little or no coding. Knowing the basics still helps you talk to engineers and grow faster.

Which software roles pay the most early in a career?

Engineering roles in AI, cloud, security and backend usually start higher, and sales roles can match them through commission. Pay grows fastest in any role when you pick a niche and show proof of work, so choose the role you will stick with long enough to get good.

How do I get my first software job while still in college?

Pick one role, learn the three starter skills for it, build one real project, put it on GitHub, Behance or LinkedIn, and apply for internships. Write about what you built. Recruiters notice students who can show work, not just certificates.

How accurate is this career quiz?

It is a starting point, not a verdict. It matches your answers to the daily work each role involves. Read the role cards, try the 30 day starter project for your top match, and you will know within a month if it fits.
